## 1. ต้องทำก่อนใช้งานจริง (ความถูกต้อง)

- [x] **พนักงานเข้า/ออกระหว่างงวด** — ใช้วันเริ่มงาน + วันทำงานวันสุดท้าย (ตั้งค่า > พนักงาน) วันนอกสภาพการจ้างไม่นับขาดงาน รายเดือนคิดตามสัดส่วนวัน (เลือกได้: ÷ วันปฏิทินของงวด หรือ ÷ 30) ที่ ตั้งค่า > กฎการคำนวณ · คนที่ออกแล้วยังได้เงินงวดสุดท้าย
- [x] **ปรับเงินเดือนระหว่างงวด / ตกเบิกย้อนหลัง** — ระบุ "อัตราใหม่มีผลตั้งแต่" ระบบแยกอัตราเก่า-ใหม่ตามวัน · ย้อนไปงวดที่ปิดแล้วจะเกิดรายการ "เงินเดือนตกเบิก" ในงวดถัดไป (จ่ายครั้งเดียว ไม่ซ้ำ)
  - ข้อจำกัด: ตกเบิกครอบคลุมเงินเดือน/ค่าแรงพื้นฐาน ยังไม่รวมส่วนต่าง OT และเงินหักขาด/สาย · ไม่คิดประกันสังคมเพิ่มย้อนหลัง
- [x] **ตรวจเลขประจำตัวผู้เสียภาษี 13 หลัก** ด้วยหลักตรวจสอบ — ตรวจตอนบันทึก (พนักงานและบริษัท) และในขั้นตรวจสอบก่อนปิดงวด
- [ ] **กรอกข้อมูลนายจ้าง** ที่ ตั้งค่าเงินเดือน > อัตรา: เลขผู้เสียภาษีบริษัท, สาขา, เลขบัญชีนายจ้าง ปกส., บัญชีธนาคารบริษัท
- [ ] **ตรวจวันหยุดประจำปี** ให้ตรงประกาศบริษัท (ตัวอย่างเป็นวันหยุดราชการทั่วไป)
- [ ] **ทดลองคู่ขนาน (parallel run)** เทียบผลกับระบบ/Excel เดิมอย่างน้อย 1–2 เดือน ก่อนเลิกใช้ระบบเดิม
- [ ] ล้างข้อมูลตัวอย่าง แล้วนำเข้าพนักงานจริง (ตั้งค่า > ข้อมูลระบบ)

## 2. งานสิ้นปี — ควรเสร็จก่อนปิดงวด ธ.ค. 2569

- [x] **ปรับภาษีปลายปี (true-up)** — งวด ธ.ค. และงวดสุดท้ายของคนที่ลาออก: ภาษีงวดนั้น = ภาษีทั้งปีจริง − ที่หักไปแล้ว · หักไว้เกินคืนในงวดนั้นได้ (ไม่เกินที่บริษัทหักไว้) · เปิด/ปิดได้ที่ ตั้งค่าเงินเดือน > อัตรา
- [x] **หนังสือรับรองการหักภาษี ณ ที่จ่าย (50 ทวิ)** — รายงานเงินเดือน > 50 ทวิ พิมพ์รายคนหรือทั้งหมด 1 ฉบับ/หน้า A4 (บันทึกเป็น PDF จากหน้าพิมพ์ของเบราว์เซอร์) — ต้องให้พนักงานภายในเดือน ก.พ. 2570
- [x] **ภ.ง.ด.1ก** — รายงานเงินเดือน > ภ.ง.ด.1ก ใบแนบทั้งปี ส่งออก CSV — ยื่นภายในเดือน ก.พ. 2570
- [x] **เงินได้และภาษีจากนายจ้างเดิม** — ตั้งค่าเงินเดือน > ข้อมูลพนักงาน (ใช้กับวิธี YTD และการปรับปลายปี)
- [x] วิธีคำนวณภาษีแบบสะสม (YTD) เป็นทางเลือก นอกจากวิธี × 12
- [ ] **ก่อนปิดงวด ธ.ค. 2569 ต้องทำเอง:** ปิดงวด ต.ค.–พ.ย. ให้ครบตามลำดับ · กรอกที่อยู่บริษัท (ตั้งค่า > ทั่วไป) และที่อยู่พนักงาน · กรอกเงินได้จากนายจ้างเดิมของคนที่เข้าระหว่างปี · ตรวจตัวเลข true-up ก่อนอนุมัติ

> ตรวจกำหนดยื่นล่าสุดกับกรมสรรพากรก่อนใช้

- [ ] ไฟล์นำเข้าโปรแกรมบัญชีตามรูปแบบที่บริษัทใช้ (Express / FlowAccount / SAP ฯลฯ) — ตอนนี้เป็น CSV ทั่วไป

## 5. ระบบและผู้ใช้

- [x] **ย้ายข้อมูลไปฐานข้อมูลจริง** — Supabase โปรเจกต์ `payroll-cmn-cil` (ตาราง `plfl_*` แยกจากระบบ HR เดิม) · ใช้หลายเครื่องพร้อมกันได้ · ตรวจเวอร์ชันกันบันทึกทับกัน · โหมดเครื่องเดียวยังใช้ได้ (`?local=1` หรือเว้น `js/config.js` ว่าง)
- [x] ผู้ใช้หลายคนและสิทธิ์ — ผู้ดูแลระบบ / HR / บัญชี-เงินเดือน / หัวหน้างาน (ไม่เห็นเงินเดือน) · บังคับด้วย Row Level Security ในฐานข้อมูล · กำหนดที่ ตั้งค่า > ผู้ใช้และสิทธิ์
- [ ] พนักงานยื่นคำขอลา/OT/แก้เวลาเอง (ESS) และหัวหน้าอนุมัติผ่านมือถือ — บทบาท "พนักงาน" และช่องผูกบัญชีกับรหัสพนักงานมีแล้ว รอทำหน้าจอ
- [x] ประวัติการแก้ไขละเอียดระดับรายการ — trigger ในฐานข้อมูลบันทึก ใคร/เมื่อไร/ฟิลด์/ค่าเดิม → ค่าใหม่ (แก้จากหน้าเว็บไม่ได้) · ตั้งค่า > ประวัติการแก้ไข
- [x] สำรองข้อมูลอัตโนมัติ — วันละครั้งเมื่อ HR/บัญชี/ผู้ดูแลเปิดระบบ เก็บ 14 ชุด + สำรองเอง 20 ชุด · ดาวน์โหลด JSON / กู้คืน (admin) ที่ ตั้งค่า > ข้อมูลระบบ
- [ ] **เริ่มใช้ฐานข้อมูล (ทำเอง):** สมัครบัญชีแรกที่หน้าเข้าสู่ระบบ → ตั้งเป็นผู้ดูแลระบบ (ดู README หัวข้อ "ฐานข้อมูลคลาวด์") → เข้าระบบแล้วเลือก "ย้ายข้อมูลจากเบราว์เซอร์เครื่องนี้" หรือข้อมูลตั้งต้นอื่น → เชิญผู้ใช้อื่นสมัครแล้วกำหนดบทบาท
- [ ] ตั้งค่าใน Supabase Dashboard > Authentication: Site URL / Redirect URLs ให้เป็นที่อยู่ที่เปิดแอปจริง (ลิงก์ยืนยันอีเมลและลืมรหัสผ่าน) และเปิด Leaked password protection
- [~] นำแอปขึ้นเว็บ — ทำเป็นเมนูใน HR Unified System แล้ว (branch `feature/payroll-full-loop` ใน hr-unified-program **ยังไม่ commit/push**) · รอ: ตรวจบนเครื่อง → รัน `supabase/002_plfl_hru_roles.sql` (สิทธิ์ HR Admin/Payroll อัตโนมัติ) → commit + push → Vercel อัปเดต
- [ ] ตัดสินใจว่าจะใช้สูตรเงินเดือนตัวไหนจ่ายจริง (Payroll Full Loop หรือ #payrun ของ HR Unified) แล้วรวมเป็นตัวเดียว (ทางที่ 2)

## ลำดับที่แนะนำ

1. ข้อ 1 (ส่วนโค้ดเสร็จแล้ว เหลืองานที่ต้องทำเอง: กรอกข้อมูลนายจ้าง ตรวจวันหยุด ทดลองคู่ขนาน นำเข้าพนักงานจริง) → 2. ข้อ 2 (ส่วนโค้ดเสร็จแล้ว เหลือเตรียมข้อมูลก่อนปิดงวด ธ.ค. 2569) → 3. ข้อ 5 ย้ายฐานข้อมูล (เสร็จแล้ว เหลือสร้างผู้ดูแลคนแรก + ESS) → 4. ข้อ 3 ไฟล์นำส่ง → ที่เหลือตามความจำเป็น
