หมายเหตุการเชื่อมต่อ Google Apps Script
หน้านี้ใช้งานร่วมกับ Apps Script เดิมของคุณได้ทันที โดยไม่ต้องแก้ไขฝั่ง Apps Script เลย:

• doPost ใช้สำหรับบันทึกข้อมูลจากฟอร์มประเมิน (ใช้ชื่อชีต HR_Evaluation)
• doGet ใช้สำหรับดึงข้อมูลทั้งหมดมาแสดง โดยหน้านี้จะ กรองด้วยชื่อ/รหัสพนักงานฝั่งเบราว์เซอร์เอง และเรียงให้รายการล่าสุดอยู่บนสุด

เพียงนำ Web App URL (ตัวเดียวกับที่ใช้บันทึก) มาใส่ในตัวแปร SHEET_URL ของไฟล์นี้ก็พร้อมใช้งาน
